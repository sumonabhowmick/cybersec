# ML pipeline

`python scripts/train_pipeline.py` validates and cleans the CSV, writes the explicit schema policy, builds a TF-IDF similarity index, and compares Logistic Regression (unigrams and unigrams+bigrams), Random Forest, XGBoost, and a TensorFlow/Keras MLP when installed for both targets. The MLP uses training-fitted preprocessing, a 128-component SVD projection, early stopping, checkpointing, and class weights. Model selection uses validation macro F1 first, then weighted F1, macro recall, macro precision, accuracy, and lower training time. Only the selected model sees test data, once, after selection.

The 70/15/15 split is seeded and stratified; all imputers, one-hot encoders, and TF-IDF are fitted inside the training pipeline. Class weights are enabled for Logistic Regression and Random Forest. The test metrics are only written after selection. Do not interpret synthetic-looking or unrun metrics as results: `data/reports/model_comparison.json` is generated by actual training.

Prediction-time features are documented in `data/processed/feature_schema.json`. In particular, targets, prior predicted labels, investigation notes, actions, resolution, feedback, false-positive labels, priority, confidence score, status, and response time are excluded.

# Model evaluation

Each target compares the same seeded 70/15/15 stratified split. Candidate selection is based on validation macro F1 before considering validation weighted F1, recall, precision, accuracy, and training cost. The final selected model is evaluated once on the untouched test partition. Reports include confusion matrix, per-class precision/recall/F1, aggregate metrics, training time, and inference time. Model metrics must be read from a report generated by running the training pipeline, not inferred from code or example values.
